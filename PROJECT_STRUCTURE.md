# Структура проекта Network Port Config Generator

## Файловая структура

```
├── server.js               # Backend-сервер Express.js (REST API + раздача статики)
├── database.sqlite         # База данных SQLite (хранение оборудования, команд, диагностики, заметок)
├── seed-db.js              # Скрипт миграции и сида базы данных из статических файлов
├── reset-password.js       # Утилита быстрого сброса/смены пароля администратора
├── template-engine.js      # Универсальный движок рендеринга шаблонов команд с переменными
├── markdown-renderer.js    # Офлайн-парсер Markdown для заметок оборудования с подсветкой кода
├── index.html              # Основной интерфейс генератора конфигураций (с модалкой заметок)
├── style.css               # Стили генератора
├── main.js                 # Клиентская логика генератора (загрузка из API)
├── admin.html              # Панель управления (Админка с редактором заметок)
├── admin.css               # Стили панели управления
├── admin.js                # Клиентская логика админки (CRUD оборудования, команд и заметок)
├── adsl.js                 # Статические шаблоны ADSL (fallback)
├── fttb.js                 # Статические шаблоны FTTB (fallback)
├── gpon.js                 # Статические шаблоны GPON (fallback)
└── sib_templates.js       # Шаблоны Сибирь (fallback)
```

## Запуск проекта

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск сервера
```bash
npm start
```
Сервер будет доступен по адресу:
- **Генератор конфигураций**: `http://localhost:3000/`
- **Панель управления (Админка)**: `http://localhost:3000/admin`

### 3. Сброс или смена пароля администратора
```bash
node reset-password.js [новый_пароль]
# или без параметров (сброс на admin):
npm run reset-password
```

### 4. Пересоздание / Сброс базы данных
```bash
npm run seed
```

## Восстановление и бэкап в Админке
- **Экспорт**: кнопка "Экспортировать JSON" на вкладке "Бэкап и База данных".
- **Импорт**: загрузка файла JSON с дампами всех таблиц.
- **Сброс**: кнопка "Выполнить сброс DB" восстанавливает стандартный набор оборудования.
